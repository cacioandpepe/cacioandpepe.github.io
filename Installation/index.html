This page explains the general process for installing TuxForge on supported devices.

Installation steps can differ depending on the device, bootloader and storage layout. Always check the documentation for your specific device before flashing anything.

Before you begin

[edit | edit source]

Before installing TuxForge:

Make sure your device is listed on the Devices page.

Read the device-specific documentation.

Back up the original firmware.

Back up important personal data.

Make sure you know how to enter recovery or bootloader mode.

Make sure you have a way to restore the stock firmware.

Warning: Experimental devices may not have a complete recovery procedure.

Find your device

[edit | edit source]

Go to:

Devices

Do not use files intended for another device. It may result in bricking the device

Download TuxForge

[edit | edit source]

Download the files listed on the release page on GitHub

Back up the stock system

[edit | edit source]

Before flashing TuxForge, make a backup of the original system.

Important things to back up can include:

- Boot partition

- Recovery partition

- Root filesystem

- System partition

- Device tree

- Firmware partitions

- NV or configuration data

- The exact partitions depend on the device.

Internal flash partition

Removing TuxForge

[edit | edit source]

To restore the original system:

Boot into the device's recovery or flashing mode.

Restore the original boot image.

Restore any modified partitions.

Restore the stock root filesystem if necessary.

Restore any configuration or NV values that were changed.

Reboot the device.

The exact process depends on the device.

See the device page for recovery instructions.

Troubleshooting

[edit | edit source]

Device does not boot

[edit | edit source]

Check:

Correct device image

Correct kernel

Correct device tree

Correct boot partition

Kernel command line

Root filesystem path

If available, collect boot logs from serial or USB.

Kernel boots but cannot find root filesystem

[edit | edit source]

Check:

Root partition

Filesystem type

Kernel command line

Initramfs

Storage drivers

No display output

[edit | edit source]

The kernel may still be running.

Try:

Serial console

USB serial

SSH

USB networking

Display support may not be implemented yet.

USB does not work

[edit | edit source]

Check the host computer with:

The device may be using another USB mode or the USB controller may not yet be supported.

Device is stuck

[edit | edit source]

Do not repeatedly flash random images.

Use the documented recovery procedure for the device and restore the last known-good backup.

Experimental devices

[edit | edit source]

Some devices listed by TuxForge are still under active development.

An experimental device may only support:

Kernel boot

Serial console

Storage

Minimal userspace

This does not necessarily mean the device is ready for normal use.

Check the device's status before installing.
